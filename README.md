# Tic-Tac-Toe Game 

A **Tic-Tac-Toe game developed in C++** as a Data Structures project.

## About the Game

This is a two-player Tic-Tac-Toe game played on a **9×9 board divided into nine 3×3 blocks**.

Players **X** and **O** take turns placing their symbols. The game checks winning conditions for both small blocks and the complete board.

## Features

* Two-player gameplay
* 9×9 game board
* 9 small 3×3 blocks
* Small-block winning detection
* Overall game winning detection
* Draw detection
* Valid move checking
* Automatic next-block selection
* **Undo and Redo functionality**
* Undo/Redo implemented using **Stack**

## Data Structures Used

* **Stack**
* **Linked List**
* **2D Arrays**
* **Structures**

## Technologies Used

* C++
* Data Structures

## Main Concepts

The project demonstrates practical use of:

* Structures

* Stack operations (`push` and `pop`)
* 2D Arrays
* Functions
* Game logic and validation

## How to Play

1. Run the C++ program.
2. The current player is displayed.
3. Enter a number from **1–81** to place your move.
4. Enter **-1** to Undo a move.
5. Enter **-2** to Redo a move.
6. Follow the displayed block instructions during the game.

## Project Purpose

This project was created to practice and demonstrate **Data Structures and C++ programming concepts** through a game-based application.
